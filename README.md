# 中文视觉梗图 500 题人工评测：大陆镜像部署说明

本目录配套的 `中国大陆镜像部署包.zip` 是完整静态网站。解压后应看到：

- `index.html`
- `assets/image1.webp` 至 `assets/image500.webp`
- `og.png`

把这些文件原样上传到任意国内静态网站托管或对象存储即可，不需要服务器程序、数据库或构建命令。

## 推荐方案

1. 使用已有的腾讯云 COS、阿里云 OSS、华为云 OBS 或其他国内对象存储桶。
2. 开启“静态网站托管”，默认首页设为 `index.html`。
3. 将压缩包中的全部文件上传到存储桶根目录，保持 `assets` 文件夹结构不变。
4. 绑定已备案的自有域名并启用 HTTPS。
5. 用手机流量打开域名，检查首页、图片、提交答案和“全部题目”界面。

也可将同一批文件部署到支持静态站点的国内代码托管平台。不要使用已经停止服务的 Gitee Pages。

## 重要说明

- 网站是纯静态的，研究者电脑关机后仍可访问。
- 每位用户的进度保存在其当前浏览器的 `localStorage` 中；退出或关闭后，用同一设备、同一浏览器、同一网址重新进入即可继续。
- 更换手机、浏览器、无痕模式或清除站点数据不会自动同步进度。建议评测者中途也下载 JSON 作为备份。
- 若以后更换域名，浏览器会把它视为另一个网站，旧域名下保存的进度不会自动迁移。
- 正式回收以用户导出的 JSON 为准；CSV 用于快速查看。

## 更新网站

以后重新生成网页后，只需再次运行 `online-site/prepare_online.py`，再用新的 `online-site/dist` 内容覆盖镜像站点文件。
